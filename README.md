# 流行り神 1・2・3 iPhone 适配研究

这是独立源码仓库。**当前完成了包内识别、资源读取组件、离线 ARM64 改写验证与 iOS 编译候选；尚未实现完整游戏运行，也没有可安装、可玩的 IPA。**

输入已从 NACP 与 CNMT 确认是《流行り神 １・２・３パック》日文版 1.0.0，本体 Title ID `010095B01AF94000`。本地现有密钥可用，不需要在聊天中提供密钥，也暂不需要连接 iPhone。

| 项目 | 当前证据 |
|---|---|
| 程序 | 4 个 NSO：main、rtld、sdk、subsdk0；64 位 ARM、Nintendo SDK 14.3.0、Nmpl 代码线索与 NVN |
| 资源 | 30 个 RomFS 文件，22 个 PS_FS_V1 归档，共 4,932 个成员 |
| 自有组件 | PS_FS_V1 原生 C 读取器；全部实际成员与 Python 解析结果一致；通过 ASan/UBSan；交叉编译为 iOS arm64 静态库 |
| 改写 | 4 个模块通过 LLVM 独立结构检查；不应用 D2R 的 cuts、obs、params |
| 等价试验 | main、sdk、subsdk0 共 26,515 站点、81,123 次试验，无分歧；150 个负例全部检出 |
| 游戏代码容器 | 已生成实验性 arm64 iOS Mach-O Guest.framework；没有宿主运行时、签名或 App |
| 游戏加载/可玩性 | 未验证；没有执行完整 SDK 启动或 nnMain，没有真机游戏画面 |

详细结果见 [技术证据](docs/EVIDENCE.md)，复跑命令与后续安装条件见 [SOP](docs/SOP.md)，范围见 [计划](docs/PLAN.md)。

下一项实际工程是本作专用的最小宿主：先验证 SDK 启动与重定位，再使原游戏标题画面产生真实 NVN 命令并输出到 Metal。本作 AudioRenderer、资源/着色器格式及触摸输入仍需适配。没有源码移植所需的游戏源码；根据当前二进制证据，暂选离线改写加平台兼容路线，但还不能证明整款游戏最终可玩。

所有派生输出限定在 `.local/` 并被 Git 忽略。原 NSP、密钥、旧 D2R 工程、旧签名配置、手机及存档均不作为新仓库内容。未配置远程仓库、未上传游戏内容。当前改写试验仍只读依赖指定版本的 D2R 通用工具；资源读取组件和包分析脚本独立实现。
