# 流行り神 1・2・3 iPhone 适配研究

这是独立源码仓库。**当前已在 Mac 上执行真实 SDK 启动与游戏初始化，并验证原 SDK CPU 音频渲染输出；尚未实现完整游戏运行，也没有可安装、可玩的 IPA。**

输入已从 NACP 与 CNMT 确认是《流行り神 １・２・３パック》日文版 1.0.0，本体 Title ID `010095B01AF94000`。本地现有密钥可用，不需要在聊天中提供密钥，也暂不需要连接 iPhone。

| 项目 | 当前证据 |
|---|---|
| 程序 | 4 个 NSO：main、rtld、sdk、subsdk0；64 位 ARM、Nintendo SDK 14.3.0、Nmpl 代码线索与 NVN |
| 资源 | 30 个 RomFS 文件，22 个 PS_FS_V1 归档，共 4,932 个成员 |
| 自有组件 | PS_FS_V1 原生 C 读取器；全部实际成员与 Python 解析结果一致；通过 ASan/UBSan；交叉编译为 iOS arm64 静态库 |
| 改写 | 4 个模块通过 LLVM 独立结构检查；不应用 D2R 的 cuts、obs、params |
| 等价试验 | main、sdk、subsdk0 共 26,515 站点、81,123 次试验，无分歧；150 个负例全部检出 |
| 游戏代码容器 | 实验性 arm64 iOS Mach-O Guest.framework；签名页映射后端通过 iOS 编译，尚未真机执行 |
| 宿主运行时 | main/subsdk0/sdk 共 62,266 次重定位；SDK Start、模块构造及游戏初始化已执行，已创建游戏工作线程 |
| 音频 | 9 段完整 ADPCM 流、3,046,472 个样本与 vgmstream 一致；原 SDK CPU 渲染探针验证双/六声道、960 帧增益与状态进度及 120 tick 环绕边界 |
| 图形初始化 | 实际建立 Metal 队列、三组 1920×1080 纹理和窗口；真实 GPU 拷贝、清屏、别名留存、同步完成/超时验证通过；尚无标题画面 |
| 游戏画面/可玩性 | 未验证；NVN/Metal、触控、存档与完整音频播放仍待实现或集成验证 |

当前已接通 CPU AudioRenderer 到 Apple 音频输出的初始化路径，正在使原游戏标题画面产生真实 NVN 命令并输出到 Metal。没有源码移植所需的游戏源码；根据当前二进制证据，采用离线改写加平台兼容路线，但还不能证明整款游戏最终可玩。

所有派生输出限定在 `.local/` 并被 Git 忽略。原 NSP、密钥、旧 D2R 工程、旧签名配置、手机及存档均不作为新仓库内容。未配置远程仓库、未上传游戏内容。当前改写试验仍只读依赖指定版本的 D2R 通用工具；资源读取组件和包分析脚本独立实现。
