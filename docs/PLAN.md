# 离线调查与适配计划

目标：为用户已有的 NSP 建立独立 iPhone 适配项目。先验证包内身份、模块和平台依赖，选择有证据支持的最小运行里程碑。

约束：旧 D2R 工程只读；不复制整包；所有游戏派生文件、密钥、签名及设备信息只留本地并忽略；没有远程发布；安装阶段前不要求连接手机。

1. 直接读取 NSP 中的 NCA 区段，提取必要的 ExeFS 和资源索引。验证：合成边界测试、与已有 hactool 的 ExeFS 输出对照、NSO 段哈希。
2. 分析 NSO 动态符号、架构、引擎线索、资源格式、平台调用及特殊指令。验证：保存可重跑脚本及精确统计，分离声明权限与实际导入，区分静态候选与运行调用。
3. 评估源码移植与二进制兼容路径。只在证明适用的部分试验离线改写与 iOS 编译；不带入 D2R 的地址表和游戏规则。验证：改写等价与编译证据；没有真实游戏入口运行就不声称可玩。
4. 保存依赖、证据、下一阶段条件和构建/安装 SOP，完成本地 Git 提交。只提交工具源代码及人工总结，不提交游戏内容。

当前假设：用户提供包是本体；经 CNMT 验证后才能成立。是否为 AArch64、是否使用 NVN、何种引擎均由模块证据决定。免费签名只能在具备真实可运行构建后使用，当前不访问手机。
