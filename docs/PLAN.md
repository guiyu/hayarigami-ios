# 独立 iPhone 适配计划

目标：从用户本地 NSP 构建独立、可安装并实际运行的 iPhone App。可安装包必须包含真实游戏运行能力；编译通过、实验框架和初始化日志都不能替代验收。

约束：旧 D2R 工程只读；不复制整包；所有游戏派生文件、密钥、签名及设备信息只留本地并忽略；没有远程发布；进入安装阶段前不要求连接手机。

1. 已完成输入身份、NSO 段哈希、资源索引与独立 PSFS 读取器验证。真实性边界见 EVIDENCE.md。
2. 已完成本作模块离线改写、独立等价试验和 Mac 原生加载；实际运行 SDK Start、游戏构造和工作线程。
3. 已验证原 SDK CPU 音频渲染与 AudioUnit 初始化，修复完整块环绕越界；真实内容听感、六声道路由和效果仍需验证。
4. 正在实现 NVN 到 Metal：资源池、纹理、窗口初始化与 GPU 同步已有测试；接下来以真实调用推进命令重放、着色器和标题画面。每次遇到新接口先确定本作 ABI，未知调用明确停止。
5. 标题画面可见后集成触控、独立存档、影片与前后台生命周期，验证剧情推进及保存恢复。
6. 构建包含宿主和已签名游戏框架的独立 iOS App；验证签名页映射、资源路径与打包完整性，再进入 iPhone 安装、启动、剧情、音视频、存档及持续运行验收。

仅提交独立工具源代码、通用授权文件、合成测试和人工证据总结。所有进度均以实际命令和运行输出为准；未完成项目保持明确未完成状态。
